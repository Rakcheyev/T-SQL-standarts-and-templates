# Learning Path (SQL)

This document describes the **recommended order** for reading the learning materials in this repository.

- Lessons are in [course/lessons/](course/lessons/).

7. [Lesson 7: Advanced query patterns](course/lessons/07_advanced_query_patterns.md)
8. [Lesson 7B: Window functions deep dive](course/lessons/07b_window_functions_deep_dive.md)
9. [Lesson 8: Transactions and concurrency](course/lessons/08_transactions_concurrency.md)
