# README (for learners)

## Для кого цей репозиторій

Цей репозиторій підійде, якщо ти:

- вивчаєш SQL з нуля або систематизуєш базу;
- хочеш пройти структуровані уроки у форматі Markdown;
- шукаєш короткі пояснення й приклади запитів у межах тем уроків.

Навчальні матеріали зосереджені у папці [course/lessons/](course/lessons/).

## Як вчити SQL за цим репозиторієм

- Почни з [LEARNING_PATH.md](LEARNING_PATH.md) і рухайся за рекомендованою послідовністю.
- Відкривай кожен урок у редакторі (наприклад, VS Code) і проходь розділи зверху вниз.
- Після читання блоку з прикладом SQL, спробуй виконати запит у своїй СУБД (та/або адаптуй під свою).
- Якщо потрібно швидко знайти тему або підзаголовок, використовуй [navigation.md](navigation.md) як довідник (або детальний індекс [navigation_detailed.md](navigation_detailed.md)).

## Теги сфери DBMS (що означають позначки)

У деяких уроках є рядок **Сфера DBMS** на початку та/або теги прямо в пунктах списків.
Ці позначки підказують, що є переносимим SQL, а що залежить від конкретної СУБД.

- `[CORE]` — переносимі ідеї/патерни SQL, які добре переносяться між СУБД (синтаксис може трохи відрізнятися).
- `[CROSS]` — концепт є у кількох СУБД, але деталі поведінки/синтаксису/продуктивності відрізняються; читай примітки й адаптуй.
- `[T-SQL]` — специфіка SQL Server / Azure SQL (Transact-SQL, інструменти або поведінка).
- `[PG]` — специфіка PostgreSQL.

Порада: якщо вчишся на SQL Server — орієнтуйся на `[CORE]`, `[CROSS]`, `[T-SQL]`. Якщо на PostgreSQL — на `[CORE]`, `[CROSS]`, `[PG]`.
